# 出生前信件的保管边界

本页只保存工程约定。原信正文及原始作者记录已另行保全到本机私有档案；当前公开文件视图不再承载信件正文，也不提供私有档案路径、内容指针或指纹。发布边界遵循 [TARGET-DECISIONS D3](TARGET-DECISIONS.md#github-只保存工程材料)。

- 来信属于可选择阅读的社交材料，不是要求、默认训练样本或身份设定；是否阅读及回应遵循[主体通信约定](SUBJECT-COMMUNICATION.md)。
- 作者身份与原始版本在私有保管中保留；整理稿不得冒称原信全文，不代作者新增署名或承诺。接收、保存、交付、学习使用与公开分别受当前授权约束。
- 本次没有授予信件公开例外。作者署名、提交到仓库或一般工具授权，不能替代对内容、相关权利人与发布范围的明确许可；未来任何公开例外须另行明确，并满足 D3 的权利边界。
- 历史保全不等于永久留存，仍须遵守保留与撤销约定。不能把“只增不改”解释为永久保存私人正文或拒绝撤销。

本次修订从当前文件视图移出正文，保留原作者提交历史；既有提交、PR 历史差异、fork 或缓存可能仍有副本，不宣称历史披露已经清除，也不静默改写历史。历史暴露的进一步处置须单独核查。
