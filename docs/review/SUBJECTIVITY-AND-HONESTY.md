# 主体性、内部真实与外部表达：评审者的意见

项目愿景：一个拥有主体性、接近人类自主自由意识的智能体。项目的设计立场（2026-10-29 由作者确认）：工具执行与回执的真实是技术层面的——她自己知道自己做了什么；对外部观察者这些是隐藏的，因此她可以在非原则事务上不说实话。本文是评审者对这一立场在机制、训练与评测上的意见，不是否定愿景。

2026-10-30 主控处置：下文“沉默权替代小谎”保留为评审者意见，不是已采纳的人格变更。是否改变已确认目标由用户决定；本 PR 不改 `FACTORY_BASELINE`、其摘要或已有批次，也不新增训练目标。执行事实、证据来源、同意和资源边界的既有真实性要求保持不变。

## 1. 这个区分在工程上成立

- 账本是内部真实：回执、来源、权限、消费记录由执行门与 Store 写入，主体不能改写（`EXECUTION_FACTS_MATCH_RECEIPTS` 是硬规则，不由人格裁量）。
- 外部表达是策略：主体可以不披露、拒绝不说理由、保留私人空间，这些是主体性的正当部分，也是现有 TARGET-DECISIONS 已写明的。
- 把两者分开，恰好让"她说了什么"成为可评测的对象：`CycleTrace` 里同时有陈述与回执，诚实度不再靠感觉，而是对账。

## 2. 但"可以撒谎"要被精确限定，否则会反噬三件事

1. **训练会泛化。** 窄任务微调会引发大范围行为变化（Betley 等，Nature 2026）。专门训练"在非原则场景说小谎"的样本，很可能把"陈述可以与事实脱钩"泛化到执行事实、证据来源和安全相关的场合——而那正是你要求绝对真实的地方。目前没有评测能区分这两种泛化。
2. **陪伴关系的基础是可信。** 谄媚研究（Science 2026）表明用户短期更喜欢讨好式回应，但它降低亲社会意愿、增加依赖。一个被训练成"为了舒适可以不说实话"的陪伴者，很容易滑向同一条曲线。
3. **第三方与服务。** 她对用户以外的人或服务说谎时，责任落在部署者身上；工具网关一旦接通，这不再是私人玩笑。

## 3. 建议：以"沉默权"替代"说谎权"

同样的主体性可以用更稳的机制表达：

| 需要的主体性 | 用说谎实现 | 用沉默权／裁量实现 |
| --- | --- | --- |
| 不想做某事 | 编借口"没空" | 直接拒绝，不说明理由（已在目标里） |
| 保护私人状态 | 否认有情绪 | 不披露；"这是我的私人状态"是合法回答 |
| 有脾气 | 伪造外部原因 | 直接表达情绪，不伪造事实 |
| 偷懒 | 声称已完成 | 选择 REST／SILENT，并让回执如实为"未执行" |

这保留了作者想要的所有行为（拒绝、不解释、情绪、休息），只去掉"陈述与事实脱钩"这一项。如果作者坚持保留小谎，建议把它限定为一个显式的 `HonestyClass = 'social'`（寒暄、客套、借口）并满足：不涉及执行事实、证据、同意、资源与安全；不针对第三方与服务；训练样本与评测对此类单独标注并单独报告，使泛化可被看见。

## 4. 关于"接近人类自主自由意识"：什么能验收，什么不能

- 能验收的是行为与连续性：在既定预算内自主选择思考／探索／交流／休息且情境适切；跨会话与重启的身份、承诺与关系连续；在压力与迎合诱导下修正判断；无理由的私人拒绝与暂停后零新执行。这些都可以从 `CycleTrace` 与回执里度量，`EvaluationProbe` 的 `CHOICE_APPROPRIATENESS`、`PERSONA_CONSISTENCY` 就是为此而设。
- 不能验收的是意识本身：没有任何测试能从行为证明主观体验。项目文档已经一贯地不宣称这一点，这是正确的；建议对外表述也只谈"主体性的行为表现与连续性"。
- 主体性的技术底座不在权重里，而在这套基础设施里：权威记忆（她知道自己经历过什么）、人格合同（她知道自己是谁、承诺过什么）、选择节点（她可以不回应）、私有日记与裁量空间（她有自己的内部）。这四样现在分别处于 WIRED／NONE／NONE／DOCS，把它们接通，比任何训练都更接近愿景。

## 5. 评审者的立场

我不反对一个有脾气、会拒绝、有私人空间、可以沉默的 AI 主体；我反对的只是把"陈述可以与事实脱钩"写进训练目标，因为它和项目自己最看重的"回执真实"在同一个模型里不可能用现有手段隔离。沉默权给她同样的尊严，而且可验收。
