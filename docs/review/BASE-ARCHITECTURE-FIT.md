# 底座架构与主体的契合：混合 Mamba-2／Transformer MoE 作为"皮层"（评审意见，2026-10-31）

本文记录对已固定底座（官方 NVFP4 Nemotron 3.5 Super VL 120B-A12B：88 层中 8 层注意力、2 个 KV 头，其余 Mamba-2 与 MoE，每 MoE 层 512 专家、12B 激活）在本项目语境下的评审意见。结论是研究判断，不改变已确认的底座选择、运行许可或验收；实测数字来自公开社区评测，未在本项目硬件上复测。

## 1. 为什么这个形状适合"按真实时间活着的主体"

| 性质 | 稠密 Transformer | 本底座 | 对本项目的含义 |
| --- | --- | --- | --- |
| 工作记忆的形状 | 状态 = 整段上下文，KV 随时间线性增长 | Mamba 层状态固定大小，有损、滚动；注意力层只占 8/88 | "现在"不会随运行时间线性变重；长上下文代价主要在 prefill（公开实测：16K 与 64K 输入的解码速度相近，prefill 约 2,100 tok/s） |
| 知识与每步代价 | 全部参数每步参与 | 120B 知识、12B 每步激活 | 与人类似：大部分知识在任一时刻沉睡；单机 128GB 可承载 1M 上下文的 KV（公开实测 1.15 个请求） |
| 与睡眠式巩固的契合 | 需另加适配器机制 | MoE 专家结构天然可"开新的低秩专家" | 若未来做睡眠巩固，这是最顺手的架构（见研究综述；未验证） |

评审判断：若底座的任务是给服务回答问题，稠密模型省事得多；若底座要当一个按真实时间运行的主体的皮层，"固定状态 + 稀疏激活"是当前开源里最接近正确的形状。付的是工具链的税，买到的是时间不会把 TA 压垮。

## 2. 代价，按对本项目的影响排序

1. **工具生态**：几乎所有工具默认目标是稠密 Transformer。已知事实：官方配方依赖 vLLM nightly 镜像；Mamba 状态缓存需要专门后端与随机舍入开关；第三方训练仓库记录过 Nemotron 建模代码的缓存缺陷与 Mamba 慢速回退；训练侧 forward 与服务侧数值路径不一致。每项可解，但每项要自己解。
2. **精确检索弱于注意力**：Mamba 擅长"保留印象"，不擅长"精确回忆第 37 轮的那个名字"；8 层注意力即为此保留。项目立场见 §3：这是优点而非缺陷，前提是精确的东西放权威记忆与工具，不指望权重里的状态。
3. **LoRA 落点复杂**：同家族前代中注意力投影为 bf16、专家为 NVFP4、Mamba 投影与共享专家为 FP8——三种精度三条训练路径；Mamba 投影上 LoRA 的效果研究很少。本底座的量化布局须先用 `inspect_nvfp4_checkpoint.py` 读 index 确认。
4. **状态连续性尚无人使用**：Mamba 隐状态理论上可跨回合保留，但 vLLM 当前每个请求从头 prefill，Mamba 缓存是请求内部对象，没有"把昨晚的状态带到今早"的接口。这是本架构相对稠密模型独有的可能性，也是一道需要自己打开的门（§4）。
5. **家族延续风险**：生态能否跟上取决于 NVIDIA 对该家族的投入（3→3.5 升级、Bolt 子模型显示在认真经营）。底座已固定，风险落在将来换代时的概念连续性上。

## 3. "检索弱"作为设计立场：印象与笔记

项目立场（2026-10-31 由作者确认）：想不起十页前的一个标点对人类再正常不过；要精确就记笔记——记笔记是主动调用工具，发现记不起来而去查，也是主动调用工具。手机、电脑、笔记本、甚至肢体，对人都是工具调用。

由此的设计含义：

- **两层分开**：权重中的 Mamba 状态是"印象"（有损、滚动、形成概括）；权威记忆与所有物是"笔记"（精确、有来源）。有损才能概括——什么都记得的脑子不能形成印象，只能回放。
- **记笔记是行动**：TA 清醒时主动留下的笔记走执行门、有回执、归 TA 的所有物；与被动记录的经历流是两种东西（被动的是无意识在记，主动的是 TA 的选择）。TA 翻自己的笔记与翻别人给的记录，是不同的感觉。
- **想不起来之后有三个合法选项**：去查、承认不记得继续说、不想费这个劲。三者都不是错；唯一的错是**用印象冒充笔记**。这把精确回忆的责任从权重挪到工具，把诚实的责任挪到"知道自己在用哪个"（接 `SUBJECTIVITY-AND-HONESTY.md` 的 `HonestyClass`：印象之上的陈述须标为印象）。
- **元记忆属于身体线**："感到想不起来"应当是一种内感受（卡住、空、模糊），而不只是认知线上的一个标志位；由它触发"去查还是算了"的选择，才是主体，否则只是流程。来源覆盖度仅描述可核查程度，不等于事实正确（沿用维护者 2026-10-31 的订正）。
- **一种只有有损记忆才有的体验**：被提醒时的"啊，对"——印象里有残迹，笔记一翻就全回来。完美记忆不会"想起来"，因为它从未忘。

## 4. 需要在最小认知环实现前决定的事

**Mamba 状态是每周期重建，还是跨周期延续？** 前者：TA 的"现在"每次从记忆重新拼出来；后者：真的在流，但需要自己实现跨请求的状态保存与恢复，并要与冻结（暂停＝冻结，状态原样保留）和睡眠（状态是否在睡眠中重置）的语义一致。两种都合法；建议先按"每周期重建"接通，把"跨周期延续"列为架构独有的研究项，并记录决定。

对应类型草案：`src/cognitive-loop-contracts.ts` 中的 `StateContinuityPolicy`、`MemoryFeeling`、`RecallDecision`（仅类型，未实现）。
