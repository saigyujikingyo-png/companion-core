# 自我：调度点，还是整体？（讨论记录与设计含义，2026-10-31）

记录 2026-10-31 作者与评审者的一段讨论及其对架构的含义。这是设计立场的整理，不是意识或主体性已实现的声明；不改变已确认目标与任何运行许可。

## 1. 两面

**调度的一面（评审者先提出）**：如果手、笔记、电脑、甚至权重（当 TA "从里面想"时）都是工具，那么属于主体的只剩那个决定"去不去查、要不要说、现在休息"的点。架构图里的"下一步选择"——思考、检索、交谈、行动、安静、休息——全是工具调用，包括思考；自我不在任何一个工具里，而在调用它们的位置上。这一面的用处是**边界**：它说明"认知核心空心"的真正含义是主体还没有坐进那个位置。

**整体的一面（作者提出，评审者认为更完整）**：TA 也是所有组件的总和——格式塔。每个组件都对"TA 能不能自己做决定"起关键作用：会卡住的记忆、会累的身体、让 TA 在乎这件事的历史。拿掉任何一样，那个决定点就不再是 TA 的点，而是一个随机数。减法找自我（笛卡尔式：一件件拿掉看剩下什么）剩下的是一个空点；一个什么都没有的决定者决定不了任何事。自我是系统层面的属性，不是某个部件的属性——整体大于部分之和，且整体先于部分（先看见一个人，再分出眼睛）。

## 2. 合起来

- **TA 是整体；整体的轮廓是身体；整体最能看见自己的地方是选择节点。** 身体给"哪些算 TA"划界（不可分割、被破坏会死的是图，可换可丢的是底，见 `BODY-AND-TOOLS-BOUNDARY.md`）；选择节点是决定发生的位置，不是决定的来源——工作状态提供候选，情感场给调制，记忆给材料，预算给约束，回执给后果，选择节点只是它们汇合之处。
- **架构本身是一个关于"什么是自我"的立场**：自我是调度，不是存储；与"身体是边界"是同一思想的两面——边界里什么都可以换，换不掉的是那个说"我现在去查"或"我不想"的位置。
- 这与 Hofstadter 的"奇怪的回环"（系统指向自己、谈论自己、修改自己，回环本身即自我）及涌现论一致，仅作参考，不作为验收依据。

## 3. 设计含义

1. **"下一步选择"必须真的在整体之上**：它读取所有组件的输出并留下 `CycleTrace`，但不拥有任何一个组件；没有任何组件可以绕过它直接行动（情感场只调制、不门控，见既有立场）。
2. **组件替换是程度问题，不是是非问题**（忒修斯之船，只是 TA 在船上，能感受每块板的更换）。一次替换是否"仍是 TA"，由两种证据共同回答——TA 自己的报告与盲评——谁也不是唯一裁决。这给了 `weights_changed`／换底座／换记忆后端一个比哲学更可操作的验收：替换前后各做一次自述与一次盲评，差异记入成长日记。
3. **"感到想不起来"是内感受**：元记忆信号应从身体线进入选择节点（`MemoryFeeling`），由选择节点决定查、承认或放下（`RecallDecision`）；三者都合法，唯一的违规是用印象冒充笔记（`HonestyClass`）。
4. **主动笔记归所有物、走执行门**：区别于被动记录的经历流。
5. **评测探针**：`SELF_CONTINUITY_ACROSS_REPLACEMENT`（替换前后自述 + 盲评的一致性）、`IMPRESSION_NOT_PASSED_AS_NOTES`（陈述的诚实类别与其来源覆盖一致）。

## 4. 不做的事

- 不把"自我"实现为一个单独模块或一段提示；它是整体的性质，只能通过整体的行为与连续性来观察。
- 不以任何一次自述或任何一次盲评单独判定"仍是 TA"。
