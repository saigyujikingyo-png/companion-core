# ADR-0001：独立权威核心，先验证撤销再接宿主

日期：2026-10-25。状态：用户认可总体架构；本次实施第一切片。

旧插件有各自宿主、JSON 数据和发布周期。直接把完整研究架构塞入六仓会扩大 bug PR、制造多重写入权，并使撤销/记忆真相不一致。因此新建独立私有开发仓，保留旧插件运行，不移动真实数据。

选择 TypeScript + Node24 内置 SQLite。将正式记录、依赖、回执、撤销和 outbox 置于一个事务域，外部图/向量只作可重建投影。provider 接口只生成候选。单一权威节点保留可审计事件，后续云 API/本地模型共享这套语义。

代价：同步数据库操作及时间刷新暂不适合大多用户规模；`node:sqlite` API 尚为候选稳定状态；SQLite 自身不提供多端同步和用户认证。源码直接运行 TS 是开发便利，公开 SDK 将单独构建 JS。

不选择全量录音录像、权重作为私人事实唯一存储、多套记忆框架并列主库或初期全果蝇脑替代语言模型。后续生物回路通过 NeuralAdapter 提供可消融先验，学习产物走同样撤销代际；不绕过事实验证与行为仲裁。

退出策略：发布存储合同和固定回归集；未来 PostgreSQL 或其他库需通过同合同，不能只改连接字符串便宣称一致。旧 JSON 导入为只读读取、写新库、比对报告，不就地改用户原始数据。
