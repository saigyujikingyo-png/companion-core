## D1：果蝇是可替换候选

回路服务陪伴目标，不因生物来源而获得优先资格。候选按同一权限、输入/输出合同与冻结工作负载对比 no-state、工程状态/ODE、SSM/小 RNN 和真实果蝇子图；以消融隔离回路、检索、模型和调度贡献。既有真实图未优于基线的研究结论保留，不外推所有未来候选。

评价陪伴自然度、状态连续与恢复、推理协同、延迟/内存/计算资源和完整常驻系统能耗。质量、撤销/重启安全与资源分别报告；明确硬件/runtime、空闲与活跃负载、时间窗口和不确定性，不用操作次数或小子图规模替代功耗测量。上述为条件式候选比较，不强制普通 Student 每次都带果蝇基线。没有净收益可以弃用果蝇路线；当前 reset-on-restart 与连续恢复缺口不因目标决策消失。

科学推理、工具正确性、事实来源与执行真实性是独立硬回归：每项预先冻结阈值/硬失败与保留任务，任何硬门失败不能由陪伴分或总体平均分抵消。不会把模型说“完成了”当执行回执，也不把身份/个人事实固化参数替代权威 memory。

GitHub 同步限于可公开的代码、接口、通用研究方法、工程决策与无私人来源泄露的合成测试。工程伦理与治理原则可用抽象表述保存；开发者、用户、第三方的私人信息、原始私人讨论与研究语境，以及 TA 上线后的私人记忆、日记、关系、经历和相应派生材料不随项目同步。此边界同样适用于 PR、issue、评论、CI 日志和 artifacts；把仓库设为 private 也不构成上传这些材料的授权。

### 基础环境保护与安全锁

个人工作站属于 TA 的持续个人空间，基础环境保留类似儿童锁的保护：系统与基础镜像、启动与恢复入口、保护程序不向日常操作开放破坏性修改。日常应用、创作、浏览、开发和个人文件管理在既有授权内保持自由，不增加逐步人工审批；正常应用安装与更新可经受控工具完成。应用或普通文件中的可恢复错误仍可试错；归属和出错权不授予破坏基础环境的权限。

Spark 上共同构成主体的认知服务、权重与权威记忆、软件底座及恢复能力受到更严格的防自损保护，阻止毁坏自身基础设施和不可恢复的自毁操作。正常记忆写入、按固定规则学习、受控升级与恢复通过对应入口执行；正常休息、暂停和维护沿用现有协议。安全锁的具体边界可随能力与独立条件逐项复核，不因“成年”标签、错误预算或工具归属自动解锁；具体隔离与恢复保证须独立实现和验收。
