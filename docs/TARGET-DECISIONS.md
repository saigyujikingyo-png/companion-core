# 目标决策：陪伴质量、可替换回路与资产边界

状态：**DESIGN_ONLY**，2026-10-26。本文记录用户目标与后续验收方向，不宣称实现、比较实验、训练或部署完成；不改历史 PASS、阴性结果或冻结研究。当前 [TJ0](TJ0-DISK-FORMAT.md)仅离线合成声明磁盘协议已实现；[TJ1](TRAINING-RUN-JOURNAL.md)真实训练仍 **NOT_IMPLEMENTED**。本决策不授权 API、训练、下载或采购。

## D1：果蝇是可替换候选

回路服务陪伴目标，不因生物来源而获得优先资格。候选按同一权限、输入/输出合同与冻结工作负载对比 no-state、工程状态/ODE、SSM/小 RNN 和真实果蝇子图；以消融隔离回路、检索、模型和调度贡献。既有真实图未优于基线的研究结论保留，不外推所有未来候选。

评价陪伴自然度、状态连续与恢复、推理协同、延迟/内存/计算资源和完整常驻系统能耗。质量、撤销/重启安全与资源分别报告；明确硬件/runtime、空闲与活跃负载、时间窗口和不确定性，不用操作次数或小子图规模替代功耗测量。上述为条件式候选比较，不强制普通 Student 每次都带果蝇基线。没有净收益可以弃用果蝇路线；当前 reset-on-restart 与连续恢复缺口不因目标决策消失。

## D2：Student v1 的质量优先级

先满足事实/权限/工具执行真实性等独立回归底线，再在可行候选中以陪伴自然度为主要选择标准，禁止单一加权平均掩盖退化。Student v1 优先自然中文、共情情境中的理解与克制、角色/关系一致、主动交流合宜及长期状态连续。共情评价针对可观察表达与行为，不推断主观情感；角色关系仍服从当前来源、许可与用户意愿，主动交流仍须合法通信窗口，不能靠频繁打扰刷分。

科学推理、工具正确性、事实来源与执行真实性是独立硬回归：每项预先冻结阈值/硬失败与保留任务，任何硬门失败不能由陪伴分或总体平均分抵消。不会把模型说“完成了”当执行回执，也不把身份/个人事实固化参数替代权威 memory。

主要自然度评价拟用盲法成对偏好，按语言（中文优先）、关系类型与会话长度分层；样本量和阈值留待预注册。独立盲评、未参与教师生成/筛选/调参/量化校准的保留集以及消融共同支撑结论；同 source/scenario family 不跨 split。分别报告维度、语言、时序跨度、退化、审阅分歧和不确定性；长期连续须实际跨会话/重启与撤销恢复证据，不靠单轮好评推导。样本不足记 INCONCLUSIVE，不虚称人类级、意识或 v1 质量已经达成。具体 rubric、预算、阈值与责任人仍待独立冻结。

## D3：通用公开底座与私有实例层

公开的是可复用通用能力，实例记忆和个性层默认私有。运行原件默认私有；通用训练履历经逐字段/许可审查生成的公开发布副本是独立产物与版本，不替代权威原件。开源发布是单独审阅流程；public lineage 标签不自动发布，private→public 不能靠改标签。任一 source/parent checkpoint/Adapter/teacher lineage 含私有数据或个性产物时，其相关派生链与后代继承私有；其余受各自许可约束。删标识、去标识、hash、摘要、蒸馏或训练不自动解除该边界。以下是分类准则，不是批量发布授权；数据公开可访问也不自动有训练或再分发许可。第一方 Apache-2.0 不覆盖第三方模型、数据、teacher 输出或其他权利。

| 资产 | 公开/私有默认及公开条件 |
|---|---|
| 通用代码、逻辑格式、codec 合同、研究方法 | 可公开；仍移除秘密/实例信息，并按各组件适用许可分发 |
| 原创合成数据、许可公开数据 | 仅在权利、用途与分发许可允许且无私人泄露时可公开；合成不自动保证无敏感来源 |
| 通用 Adapter | 仅在训练来源/teacher/base/衍生物许可允许分发、无私密或可泄露实例内容并通过发布审查时可公开 |
| 私有实例记忆、真实聊天/经历 | 私有，按当前授权、用途/保留/撤销策略处理；不得随底座或格式公开 |
| 私人或可泄露的派生训练集、个性 Adapter | 继承私有；摘要/翻译/去标识/训练不自动解除来源边界，不能据权重形式宣称安全公开 |
| 私有实例训练履历正文与叙事视图 | 继承私有，含原因、来源/许可、step/loss、配置和产物关联；不因“只有 metadata”默认公开 |
| 通用训练履历 | 仅全字段无私密、无可泄露关联且许可允许才可公开；保留可核验来源但不泄露私人引用 |
| 内容指针、hash、索引、字典、运行环境字段与缓存 | 随关联内容逐项分类；低熵 hash/路径/关联关系也可能泄露，不能作为默认安全脱敏手段 |

私有运行资产位于源码/OneDrive 之外的受控存储，公开仓库只存允许公开材料。冷持久不等于永久留存；权限、撤销、保留和恢复仍依独立协议。撤销记录或数据不等于权重 unlearning，泄露风险和受污染产物按 lineage 处理。
