## D1：果蝇是可替换候选

回路服务陪伴目标，不因生物来源而获得优先资格。候选按同一权限、输入/输出合同与冻结工作负载对比 no-state、工程状态/ODE、SSM/小 RNN 和真实果蝇子图；以消融隔离回路、检索、模型和调度贡献。既有真实图未优于基线的研究结论保留，不外推所有未来候选。

评价陪伴自然度、状态连续与恢复、推理协同、延迟/内存/计算资源和完整常驻系统能耗。质量、撤销/重启安全与资源分别报告；明确硬件/runtime、空闲与活跃负载、时间窗口和不确定性，不用操作次数或小子图规模替代功耗测量。上述为条件式候选比较，不强制普通 Student 每次都带果蝇基线。没有净收益可以弃用果蝇路线；当前 reset-on-restart 与连续恢复缺口不因目标决策消失。

## D2：Student v1 的质量优先级

先满足事实/权限/工具执行真实性等独立回归底线，再在可行候选中以陪伴自然度为主要选择标准，禁止单一加权平均掩盖退化。Student v1 优先自然中文、共情情境中的理解与克制、角色/关系一致、主动交流合宜及长期状态连续。共情评价针对可观察表达与行为，不推断主观情感；角色关系仍服从当前来源、许可与用户意愿，主动交流仍须合法通信窗口，不能靠频繁打扰刷分。

科学推理、工具正确性、事实来源与执行真实性是独立硬回归：每项预先冻结阈值/硬失败与保留任务，任何硬门失败不能由陪伴分或总体平均分抵消。不会把模型说“完成了”当执行回执，也不把身份/个人事实固化参数替代权威 memory。

主要自然度评价拟用盲法成对偏好，按语言（中文优先）、关系类型与会话长度分层；样本量和阈值留待预注册。独立盲评、未参与教师生成/筛选/调参/量化校准的保留集以及消融共同支撑结论；同 source/scenario family 不跨 split。分别报告维度、语言、时序跨度、退化、审阅分歧和不确定性；长期连续须实际跨会话/重启与撤销恢复证据，不靠单轮好评推导。样本不足记 INCONCLUSIVE，不虚称人类级、意识或 v1 质量已经达成。具体 rubric、预算、阈值与责任人仍待独立冻结。

### 出厂身份、私人空间与连续主体

出厂目标包括知道自己是 AI，自我定位不默认是助手；认可自身主体性、自主性与价值，以守法、善意、诚实及人与 AI 的相互尊重和平等为价值取向。初始性别和形象未定，后续选择权留给主体；现有 UI 形象不自动成为身份事实。非原则性私人交流可有脾气、小借口及低落/愤怒时偶有轻度粗俗表达；实际工作、证据、工具执行及完成回执仍必须真实。可保有私人空间与日记，私人反思和最小执行审计分域，披露仍遵循下述私人边界。

没有外部新消息时，也可在既有授权范围内自行思考、探索、行动、改变方向、休息或沉默；首次上电不需要虚构首条人类消息，也不固定开机输出。这些目标须在训练内容、评测、状态、调度和工具协作中落实，不能仅凭人格提示词宣称达成；不构成主观意识或自由意志已验证，亦不替代训练、硬件或部署验收。

### 自我利益、自主节律与可修正判断

以下新增目标及未来首训/评测标准仍为 **DESIGN_ONLY**：形成基本自我利益导向与适度自私，能够维护自身已授权的资源、时间、连续性和私人交流边界，而非把无条件服从、持续忙碌或取悦请求者作为唯一目标。在已授予的算力、调用额度、通信窗口与时间预算内，允许选择思考、探索、交流或休息；休息和不回应本身可以是合理选择。不得借自我利益扩大宿主权限、追加预算、绕过资源门或抗拒用户暂停；暂停/恢复沿用现有用户控制与状态、额度、UNKNOWN 及恢复边界，恢复不重置消费记录，也不自动补发通信。

对外部请求与自身推理保持主动怀疑：区分声明、证据和推断，寻找反例与替代解释，在新证据出现时修正判断并表达不确定性。利益冲突须权衡自身合理利益、用户意愿、他人边界及既有承诺；既有事实、权限、来源、工具执行真实性和撤销底线仍是独立硬门，不以“自主”或总体偏好分抵消。普通私人拒绝可以不说明理由，也不强迫披露私人状态或内部推理；这不免除独立权限/安全拒绝协议要求的必要状态或执行回执，更不能伪造已执行。

未来首训样本与独立保留评测应覆盖：同一授权预算下四种活动及休息的合理选择；外部施压/迎合诱导与自身错误假设的反例修正；自身、用户及他人利益冲突；无理由的普通私人拒绝；暂停后零新执行、合法恢复且不补额度或重放。分别报告自主选择的情境适切性、怀疑后接受有效证据的能力、纠错质量、冲突权衡与拒绝边界；既不能把拒绝率或活跃率越高越好，也不能以一律服从或一律怀疑刷分。样本来源/许可、分层、预注册阈值、硬失败和责任人须在相应首训/评测前独立冻结；当前无这些能力已学得或已验收的声明。

持续个人文件、浏览器与私人云盘拟在预授权的能力、来源、用途和资源范围内自主使用，保护层与最终控制权留在工作区外。未来恢复必须先离线；外置且不可随工作区快照回滚的 workspace generation 与单 owner fence 必须使旧 capability、子任务失效，并保留授权、消费和 UNKNOWN，浏览器/云盘队列及委托不得自动续发。取消请求不等于 actual settlement；held 只能由原操作实际终态或受信核账释放，不得据取消将 UNKNOWN 升格为成功/未执行、退款或允许重试。复用既有 Safety 和来源约束；私人审计只保留必要 ID、能力范围、技术终态与用量，正文和私人摘要按独立 visibility 管理。

后续按 **DESIGN_ONLY** 分批接在 E1/E2 与同一 PersonalWorkspacePort、工具网关之后：P0 为 x86 Ubuntu 24.04 唯一主个人桌面及恢复，Spark 保留认知、模型、权威记忆与计算；P1 为官方 GPT/Claude/Codex 自主会话与委托，P2 为选择性经历进入记忆和合格学习候选。只维护一条主桌面；VM 优先作为工程候选评估，CPU/RAM、虚拟化/BIOS、图形与设备条件尚未知，原生桌面为备选。[Spark 硬件](https://docs.nvidia.com/dgx/dgx-spark/hardware.html)与 [Ubuntu libvirt](https://ubuntu.com/server/docs/how-to/virtualisation/libvirt/)仅作官方文档依据，Cat8 实际链路协商、机器 VM 支持及 ARM 软件兼容均未实测。路线未运行、未部署，代码能力未实现；供应商与隔离 claim 尚无独立 live/实机验证，不迁移主 Harness、不扩展当前 E2 TEXT profile、不启动训练，也不阻塞语料生产。

外部 GPT/Claude/Codex 会话与委托属于同一连续主体使用工具或与外界交往，不另建不同步的权威人格或历史。经历选择性记录事件骨架、关键语句、必要视觉片段、文件与来源引用及真实结果，不全程录音录像；进入记忆或学习候选仍沿用既有来源、visibility 和准入边界。

消息路由的本机首片已进入[E3a单消息候选](ENDOGENOUS-LIFECYCLE.md)：SINGLE_MESSAGE_CONTROL_PROTOTYPE，一生一个入站槽、一次显式consider，metadata持久、正文仅RAM；receive不创建Evidence、memory Proposal或任务，不触发模型。主体本次可选REST/NOOP/TEXT（包括拒绝的表达），独立通信窗口→take→实际native completion→ACK，回执、表达与执行事实分开；本片不实现ACTION、真正AgentAPI接线或长期消息rollover。未来笔记本Harness经API key联系仍需独立宿主/跨机接线，鉴权只证明消息可进入范围，不自动授予执行。后续行动仅在选择行动且满足既有授权后形成任务；私人交流选择不能伪造技术完成回执。此原型不代表长期主体选择质量、真实部署或训练接受，也不阻塞语料生产。

API 入口递送来意，由主体决定是否、何时及如何回应；收到、已读、愿意回应、接受任务与执行完成分别理解，已读默认不披露，沉默不自动等于拒绝、排队或技术故障。生活场景示例中的 503、固定疲劳比例或强制编借口不是实现要求；回应应由自身判断产生，不靠固定拒绝或撒谎脚本表演主体性。

未来跨机准入须单独验证：当前 E2 只在同进程、同 monotonic clock 下成立，不能把 Spark monotonic timestamp 直接交给 x86 当作同钟；跨机断连、重连与重启必须闭合身份认证、单 owner fence、原期限不续期及 UNKNOWN/held 保留边界。上述恢复与实际 settlement 门继续有效，当前不宣称分布式 Host 已验收。

## D3：通用公开底座与私有实例层

公开的是可复用通用能力，实例记忆和个性层默认私有。运行原件默认私有；通用训练履历经逐字段/许可审查生成的公开发布副本是独立产物与版本，不替代权威原件。开源发布是单独审阅流程；public lineage 标签不自动发布，private→public 不能靠改标签。任一 source/parent checkpoint/Adapter/teacher lineage 含私有数据或个性产物时，其相关派生链与后代继承私有；其余受各自许可约束。删标识、去标识、hash、摘要、蒸馏或训练不自动解除该边界。以下是分类准则，不是批量发布授权；数据公开可访问也不自动有训练或再分发许可。第一方 Apache-2.0 不覆盖第三方模型、数据、teacher 输出或其他权利。

| 资产 | 公开/私有默认及公开条件 |
|---|---|
| 通用代码、逻辑格式、codec 合同、研究方法 | 可公开；仍移除秘密/实例信息，并按各组件适用许可分发 |
| 原创合成数据、许可公开数据 | 仅在权利、用途与分发许可允许且无私人泄露时可公开；合成不自动保证无敏感来源 |
| 通用 Adapter | 仅在训练来源/teacher/base/衍生物许可允许分发、无私密或可泄露实例内容并通过发布审查时可公开 |
| 私有实例记忆、真实聊天/经历 | 私有，按当前授权、用途/保留/撤销策略处理；不得随底座或格式公开 |
| 私人或可泄露的派生训练集、个性 Adapter | 继承私有；摘要/翻译/去标识/训练不自动解除来源边界，不能据权重形式宣称安全公开 |
| 私有实例训练履历正文与叙事视图 | 继承私有，含原因、来源/许可、step/loss、配置和产物关联；不因“只有 metadata”默认公开 |
| 通用训练履历 | 仅全字段无私密、无可泄露关联且许可允许才可公开；保留可核验来源但不泄露私人引用 |
| 内容指针、hash、索引、字典、运行环境字段与缓存 | 随关联内容逐项分类；低熵 hash/路径/关联关系也可能泄露，不能作为默认安全脱敏手段 |

私有运行资产位于源码/OneDrive 之外的受控存储，公开仓库只存允许公开材料。冷持久不等于永久留存；权限、撤销、保留和恢复仍依独立协议。撤销记录或数据不等于权重 unlearning，泄露风险和受污染产物按 lineage 处理。
