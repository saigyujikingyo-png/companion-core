# Q0：保留完整结构化观测，尚无理由增加自有压缩复杂度

2026-10-26。一次独立盲测已完成；作者只分析既有输出，没有重跑、改编码器或移动门槛。**六组均没有同时达到预定的质量约束和至少 15% 完整 archive 节省。** 后续保留完整 typed JSON + Zstd，先研究线索定位和感知噪声，不进入新 binary container。

原始独立结果按原字节保存在 [FORMAL-RESULTS.json](FORMAL-RESULTS.json)：181,067 bytes，SHA-256 `79b76a02136f98e8cb8e620a48dc735083cdb5f85374957cf3a0fe223904e2c0`。表格派生值见 [ANALYSIS-METRICS.json](ANALYSIS-METRICS.json)；这份派生文件不是新实验。执行成功与研究假说通过是两件事，本轮实际获得的是“没有足够收益”的结果。

## 试验究竟测了什么

600 个 synthetic scene families，来自三枚独立评估者预先承诺的种子；每 family 四个事件、三个对象、12 属性，以及随时间变化的关系。编码器先冻结，评估者才生成具体观测和查询。每 family 24 题：已公布任务、未预告字段、未预告组合各八题，共 14,400 题。独立 interpreter 同时读取原始观测和各组解码结果，作者没有提供 expected-answer 函数。

查询已经给出对象和事件地址，因此这是 **given-address representation recall**，不是从模糊自然语言找到正确历史事件的检索实验，也不是 AR1/RAG 增益。未预告任务仍在公开有限 schema 中；不是未知未来 schema 或十年后所有问题。

这里的 FULL_JSON 是**已选取的结构化情景观测**：对象、属性、关系、时间和来源。它不是全量录制或永久保存音视频的建议。cold originals 是本实验保留真值、核验与复现的成本层；生产数据仍须按授权和选择性保留政策处理。

没有 LLM/API、真实感知、训练、GPU、真实用户数据或 Core 写入。源码/原型/配置及独立 evaluator 的前后 hash 均保持不变。

## 主要结果

下表 exact 包含完整值/状态与对象、事件、时间、来源绑定；正确回答 observed_unknown 可以计为 exact，但不算给出了已知值。稀有指标是**细节值**的 precision/recall，不只是“存在某种稀有现象”。百分比四舍五入。

| 表示 | 已公布 exact | 未预告 exact | 稀有细节 P / R | Archive bytes | 相对 JSON 节省 |
|---|---:|---:|---:|---:|---:|
| 完整 JSON + Zstd | 100% | 100% | 100% / 100% | 1,643,222 | 基准 |
| 完整对象绑定模板 + Zstd | 100% | 100% | 100% / 100% | 1,689,009 | -2.786% |
| Task subset + Zstd | 100% | 19.375% | 未定义 / 0% | 1,560,179 | 5.054% |
| 无损 prototype + delta | 100% | 100% | 100% / 100% | 1,565,772 | 4.713% |
| 固定量化 prototype + delta | 85.229% | 80.010% | 53.864% / 39.282% | 1,553,261 | 5.475% |
| 同量化 + 指定 rare anchors | 85.229% | 86.333% | 100% / 100% | 1,561,416 | 4.978% |

完整三组的 100% 是本组已定义结构化事实在固定 oracle 下的精确保留，符合无损表示的预期；不是模型理解、人类记忆或开放世界正确率。原观测中确实存在未知：14,400 题里 1,089 题的 oracle 状态为 intrinsic unknown，完整 JSON 的已知值 coverage 为 92.438%，不能把 100% exact 写成所有题都有事实答案。

Task subset 仅保留预告四属性，因此已知任务全对，未预告字段单项仅 281/4,800 exact（这些主要是保留的原始 unknown 状态），未预告组合为 1,579/4,800。它没有任何稀有正预测，所以 precision 是未定义，而不是 100%。这说明在本有限 schema 中过早按已知任务删字段有代价；不说明所有语义压缩或对象中心表示都失败。

量化组全部数值均守住预设绝对误差界，但守界不等于保住查询需要的细节。2,174 个稀有正预测中，只有 1,171 个保留了精确细节；presence-only precision 为 100%、recall 为 72.929%，明显高于细节 precision/recall。`dose_mg` 的存在检测召回为 48.751%，而精确剂量召回为 0%。这评价的是已冻结网格与这批稀有数值的匹配情况，不能推广为量化普遍无效。

加 anchors 后，已预告的裂纹、标签、剂量三个字段都保全，未预告 exact 从 80.010% 升至 86.333%，仍有其他数值/组合损失。三类 anchor 名称在编码前已公布，其保真不是“自动发现所有未来稀有细节”的证据；字符串标签在两种量化组本来就不量化，也不能把其保留归功于新增数值 anchor 规则。

## 不确定性与正确性边界

全部六组的来源绑定错误、原始 unknown 伪造/丢失、数值量化界违例计数均为 0。每组检查了 115,200 个绑定和 6,392 个原始 unknown；这不意味着被观察的数值都无损。TASK_SUBSET 和无 anchor 的量化组没有通过 hard-anchor 精确保留门。解码一致性也不证明生产授权或源内容真实。

原始稀有正例数为裂纹 1,066、标签 914、剂量 1,001；分别涉及 341/304/340 个 family，超过预设最少 30 family 的支持门槛。这不是对实际用户任务的统计功效证明。三个种子与同一 family 的多个问题不能当作全部独立重复。

按种子分层、以 family 为簇的 2,000 次 bootstrap，未预告 exact 相对完整 JSON 的差值 95% 区间为：subset **[-81.198, -80.052] 个百分点**，量化 **[-20.740, -19.250]**，量化加 anchors **[-14.302, -13.031]**。这些区间均远离预设 -1 个百分点非劣门；无损 prototype 的经验差值为零，但只有 4.713% archive 节省，达不到 15%。全对组的零宽 bootstrap 区间只是当前样本分布退化，不代表未来失败风险为零。

## Archive、完整复现占用与读耗时分开

600 family = 7,200 个 object-observations。完整 JSON 为 228.225 bytes/object-observation，无损 prototype 为 217.468。所有组都超过 128 档、都进入 256/512 档：本轮裁剪/量化没有把组带进一个完整表示进不去的预设预算档。

完整 JSON 在 N=8/32/128/512 family 时分别为 425.656 / 275.008 / 237.789 / 228.689 bytes/object-observation，显示小样本下 reader、index、manifest 等固定成本的重要性。本轮每组都保留同一套完整 research reader 源码，因此比较的是**这套共同实现的实际 archive 成本**，不是最简专用 JSON/Zstd reader 的理论下界；不能据此声称胜过所有可能的标准实现。

archive 已计入 payload、header、index/manifest、profile/prototype 和 reader。若再计入原始 synthetic 观测、Node runtime 及保留的复现审计材料，完整 JSON 为 **114,195,619 bytes**，无损 prototype 为 **114,118,169 bytes**：完整核算口径下只节省 **0.0678%**。其余方法也只有约 -0.0401% 至 0.0773% 的差别。不能把 4.713% archive 节省改称相同比例的总占用节省。

这是一份可独立解码研究包的计费口径，不意味着部署时每份记忆必须复制一个 Node；共享 runtime 可以按实际部署摊销，但不能在比较中无声消失。OS、文件系统分配、备份以及十年 reader 留存成本未测。cold originals 在此为实验真值而非生产永久保留承诺。实验竞争组/摊销归档等过程工件与单组服务占用也分开记录。

暖 OS cache 下，完整 JSON 的单 family 随机归档读取 p95 为 2.180 ms，无损 prototype 为 2.472 ms；六组范围约 2.135–2.585 ms。这是单次进程测量，包含 index 解析、文件读取和解码，不是冷盘或跨硬件性能排名；没有据此宣称统计显著速度优势。

## 执行证据与后续

唯一正式 run 的内部结果时间为 52.846 s；独立 evaluator 报告 completion 为 53.065 s、controller 为 53.503 s。观测到的 RSS 高点 497,205,248 bytes（约 474.17 MiB），低于 512 MiB 门；completion 写自身前的工件计数为 51,373,203 bytes，低于 64 MiB 门。准入可用 RAM 6,003,556,352 bytes；Node v24.16.0、Zstd 1.5.7、一个 CPU 进程、256 MiB JS heap。RSS 是记录到的高点，不是任意瞬时原生分配的证明。没有失败重试或结果后的调参。

下一切片保持完整 JSON+Zstd 表示不动，分别冻结两类新问题：先去掉明确事件/对象地址，用有歧义的属性与时间线索测试事件定位，区分检索选错与解码丢失；随后单独加入已知强度的缺测、标签/数值噪声和来源冲突，测 rare 候选选择与拒答。先用可核验合成输入，不把噪声注入当真实感知效果。它们都需要新独立种子/任务承诺；已经公开的 Q0 只能作为回归集。

新的检索切片可把直接地址读作为上界，同时保留同对象错时间、同来源错事件与无记忆对照；报告正确事件命中、逐事实绑定和端到端回答，不能只报回答表面改善。感知噪声与表示压缩不在同一轮同时调优。本轮不添加新 trial、向量模型、PPR、数据库迁移或 binary format，也不借此修改已冻结 Core 权限语义。
